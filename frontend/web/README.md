# VIA — Frontend

Aplicação web do projeto VIA, desenvolvida com React,
TypeScript, Vite e Tailwind CSS.

## Executar

Instalar dependências:

npm install

Iniciar desenvolvimento:

npm run dev

Verificar qualidade:

npm run lint

Gerar build:

npm run build
